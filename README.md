# Immersive Paintings Blocks Mod

**Minecraft Version:** 1.21.1 | **Mod Loader:** NeoForge

*This mod adds an item to convert Immersive Paintings Graffiti and Glowing Graffiti into blocks instead of entities*

**Why does this mod exist?**

This mod exists for two reasons:
1. To make Graffiti and Glowing Graffiti more performant for the server and client by converting it from an entity to a block.
2. To make Graffiti able to be attached to Create Mod contraptions.

**Important Note:** *Converted graffiti is no longer editable.*

**Converter Item**

Craft the converter item from Graffiti and a Slime Ball or Graffiti and a Super Glue item from the Create Mod.

**Thickness**

Converted graffiti can be made "thicker" by clicking converted graffiti blocks with the converter item.
Thickness adds depth to the graffiti and if the graffiti was glowing graffiti, the thicker the graffiti block, the more light it will emit.

**Config**

The distance that the converted Graffiti Blocks will render from the player can be configured in the Client Config.

The default is 256 blocks and can be increased to 512 and decreased to 1. 
Decreasing will improve clientside FPS performance. Increasing will reduce clientside FPS performance.

**Dependencies**
- Immersive Paintings Mod (NeoForge)
- Immersive Paintings also requires the Fzzy Config mod and the KotlinForForge mod.
